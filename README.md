## How to Run

1. Download or clone this repository.
2. Make sure you have the Java Development Kit (JDK) installed.
3. Open a terminal in the directory containing the `hw2` folder.
4. Compile and run:

   ```bash
   javac hw2/*.java
   java hw2.Main
   ```

5. Hey so just enter numbers into the calculator. 

## Example

```text
type your infix expression: 3+4*2
answer is 11.00
```

The program also displays the converted postfix expression.

## Limitations

This calculator does not currently handle division by zero or negative numbers correctly. Please use supported expressions when testing.
